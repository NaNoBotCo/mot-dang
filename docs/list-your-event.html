📣 ลงงานของคุณList your event

ลงงานของคุณในมดแดง ฟรี ไม่มีค่าใช้จ่าย ไม่มีเงื่อนไขแอบแฝง จะเป็นงานประจำทุกสัปดาห์หรืองานครั้งเดียวก็ได้List your event on Mot Dang. Free, no charge, no catch — a weekly regular or a one-off, both are welcome.

บอกเราแค่นี้Just tell us

  • ชื่องานEvent name
  • วันและเวลาDate and time
  • สถานที่Venue
  • ราคา (ถ้ามี)Price, if any
  • ลิงก์A link
  • ประจำทุกสัปดาห์ไหมWeekly or one-off?

ส่งงานผ่าน GitHubSend it via GitHub

ไม่มีบัญชี GitHub ก็ไม่เป็นไร ส่งมาทาง Ko-fi ได้เลยเจ้าNo GitHub account? Send it via Ko-fi instead and we will add it. Ko-fi

ถึงคนที่ทำปฏิทินอยู่แล้วIf you already run a calendar

ถ้าคุณทำจดหมายข่าวหรือปฏิทินงานอยู่แล้ว เรายินดีลิงก์กลับหาคุณเสมอ และถ้าคุณมีฟีด (RSS / iCal) เราดึงอัตโนมัติได้ ไม่ต้องพิมพ์ซ้ำAlready run a newsletter or a calendar? We link back, always. And if you publish a feed — RSS or iCal — we can read it automatically so you never type anything twice.
