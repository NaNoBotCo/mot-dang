Written spec

Word budget
Nine visible words, all functional: brand (1), language modes (3), cities (2), the every-shelf link (2), easy-read glyph (1). Numerals, icons and symbols are exempt — they read in both languages at once, which is how a bilingual page gets to near-zero words without picking a side.
Icon legend · accessible names
Map trifold → แผนที่ · Map. Calendar → ปฏิทิน · Events. 24°/9 tile → อากาศ-ฝุ่น · Weather + PM2.5 (links to widgets). Red phone → ฉุกเฉิน · Emergency (opens sheet 1b: 1669 · 191 · 199 · 1784 · 1155 + chuai). Plus-circle → เพิ่มข้อมูล · add a place. Chats → คุยกับมด. Code → source & raw data. Every icon has title + aria-label in both languages; desktop shows tooltips on hover, mobile on long-press.
Search is the directory
Focusing the empty box lists all 28 shelves (with counts) as suggestions; typing matches names, shelves, tags, sois and numbers, Thai or English, and the mic runs speech input. The every-shelf link and all.html remain the no-JS path to everything — nothing from today's site is dropped, it is re-entered through search.
Layout & palette (inferred — confirm with a screenshot)
Paper #faf8f2, ink #211d18, ant red #c62f22 (brand, search, emergency only), hairline #d8d2c4, selected fill #f0e9dc. Center column max 560px; targets ≥44px (icon tiles 52px mobile); body 15px, easy-read 18px with labels shown. Below 1024px the desktop and mobile layouts are identical apart from the "/" hint and mic.
Order of first paint
Logo → search → cities → four tiles → shelf link → footer glyphs. One column, no scroll on any phone taller than 640px. Everything after the search box is optional chrome; the page is usable the moment the box renders.

System rules
· Type: 15px body, 12–13px meta, headings by size not weight (max 600). Thai set in the same stack, never smaller than its English pair.
· Spacing: 4/8/12/16 rhythm; list rows ≥48px; one divider weight everywhere.
· Color: neutral ground, one accent for interactive things only. Counts and meta are neutral-500 — data never shouts.
· Easy-read mode: bumps body to 18px, row height to 60px, meta to full opacity — same layout, no separate page.
· No JS required for any content page; search, sheet, and expand degrade to plain links and anchors.
