4. LANDMINES. EVERY ONE OF THESE COST ME REAL TIME TODAY.
==============================================================================

**`grep` treats docs/md.js as BINARY and silently matches nothing.** I
concluded four times that a good deploy had shipped nothing. Use python:
    python3 -c "print(open('docs/md.js',encoding='utf-8').read().count('X'))"

**A trailing `grep -c` returning 0 exits 1** and makes a successful deploy
look failed. Read publish/deploy.py's log for "site synced", not the exit
code of your shell chain.

**The search page has TWO test files and they cover different halves.**
  tests/test_search.py       lifts `md:search-pipeline` — matching only.
  tests/test_search_page.py  lifts `md:search-render` — the DOM half. NEW.
I wrote the second one because I put `const partial = worst==='partial'`
ABOVE `const worst = ...`, a temporal dead zone, and **every search on the
site threw a ReferenceError while test_search.py passed 32 of 33 cases** —
the fault was four lines below where it stops looking. If you edit the render
half, run test_search_page.py. It also holds CSS contracts (P1, P2, and the
stylesheet-versioning guard) because those live in the stylesheet where the
render test cannot see them.

**`tests/test_search.py` has ONE pre-existing red case: `zzzzqqq` finds 3
rows at the loose tier ("SK House").** I verified it red on the live index
BEFORE any of this work. It is not mine and I left it deliberately: loosening
thresholds is a fleet-wide matcher change with its own eval.

**A build is ~25 minutes and wipes docs/.** `cache/build.lock` is enforced.
To verify while someone else holds docs/, import build, point `build.DOCS` at
a scratch dir, call `build()`. That takes no lock.

**A browser will lie to you about a deploy.** Serve the scratch build on a
FRESH PORT to get a cold cache, or you will screenshot yesterday's page and
believe it.
