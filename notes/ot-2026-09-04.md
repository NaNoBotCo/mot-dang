   `amenity=clinic`, the Doi Saket physio node is `amenity=doctors`. So the
   child is hidden — and `/longcare.html` (WO-32) linked to
   `cm/medical/physio/index.html`, a page that has never been built, on a
   live page since 26 Aug. Fixed: the link now goes to the specialty search
   for กายภาพบำบัด and to /ot.html. (Filling the shelf is a separate order —
   cmhy.city lists ~20 CM physio clinics; see the follow-ups list.)
2. **OSM has no OT tag in use here.** `healthcare=occupational_therapist`
   exists in the wiki; zero elements in CM/CR carry it. The rule is now in
   `MEDICAL_SUB` (→ the rehab shelf) so the first mapped one lands.
